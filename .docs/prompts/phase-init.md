# Промпт: Создание новой фазы

Скопируй текст ниже и вставь в Cursor.

---

Нам нужно спланировать новую фазу разработки.

Прочитай эти файлы:
- @CLAUDE.md — архитектура и правила проекта
- @.docs/prd.md — полный список функциональности и роадмап
- @.docs/database.md — схема БД
- @.docs/phases/_status.md — какие фазы уже есть
- @.docs/phases/ — прочитай существующие phase-N.md чтобы понять что уже сделано
- Если есть папка `.docs/ref/prototypes/` — прочитай список образцов экранов, а также @.docs/design/direction.md и @.claude/rules/design.md

Затем:
1. Определи следующую фазу на основе роадмапа из prd.md и статусов из _status.md
2. Предложи что входит в фазу — коротко опиши цель
3. Раздели на таски (каждый таск = 1-2 дня, 4-7 файлов)
4. Для каждого таска укажи: цель, файлы, DoD
5. Если дизайн подключён (есть `.docs/ref/prototypes/`): для каждого таска с интерфейсом укажи файл-образец из `prototypes/`; в Фазе 0 добавь таск «Подключить стили: `public/assets/css/`, шрифты, макеты `layout/` и админки» (по `.claude/rules/design.md`). Экран без образца пометь «образца нет» и не придумывай его вид
6. Жди моего подтверждения
7. После подтверждения создай файл .docs/phases/phase-N.md

За основу структуры возьми @.docs/phases/phase-example.md

Не пиши код. Только планирование.
Жди подтверждения перед созданием файла.
