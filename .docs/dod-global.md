# Global Definition of Done

Эти критерии применяются к каждому таску.
Проверяй вручную перед тем как считать задачу выполненной.
Разделы, которых таск не касается, пропускай.

---

## UI
- [ ] Страница открывается без ошибок
- [ ] Нет сломанной вёрстки
- [ ] Страница корректно отображается на мобильном (320px+)
- [ ] Если есть образец в `.docs/ref/prototypes/`: расположение и состав экрана совпадают с ним; расхождения описаны в отчёте по таску

## Данные
- [ ] После отправки формы — запись появляется в БД
- [ ] Выводится уведомление об успехе или ошибке
- [ ] Данные других пользователей недоступны (изоляция по user_id)
- [ ] Пользователь не может увидеть или изменить чужую запись,
      даже подставив чужой id в URL
- [ ] Если операция меняет несколько таблиц (или связана с деньгами),
      она либо проходит целиком, либо откатывается транзакцией — не
      бывает наполовину применённых

## Безопасность
- [ ] Незалогиненный пользователь не может открыть защищённую страницу
- [ ] Если страница или действие только для админа — проверяется
      `role = 'admin'`, а не только факт логина (обычный пользователь
      не должен попасть в админку, зная URL)
- [ ] Вывод данных в Views через `e()` / `htmlspecialchars()`
- [ ] Формы с POST имеют CSRF-токен: поле выведено через `csrfField()`
      **и** контроллер вызывает `requireCsrf()` /
      `verifyCsrfToken()` до изменения данных — само по себе поле в
      HTML ничего не проверяет
- [ ] Значения, от которых зависят деньги и доступ (цена, остаток,
      роль), берутся на сервере из БД, а не из данных, присланных
      клиентом
- [ ] Вход и публичные формы ограничены по частоте попыток —
      `tooManyAttempts()` / `hitRateLimit()` / `clearRateLimit()`
      (проверить вручную серией быстрых повторных запросов)
- [ ] Вход, регистрация и восстановление пароля не показывают, что
      именно неверно: «неверный email или пароль», а не «такого
      пользователя нет» (иначе перебором узнают, кто зарегистрирован)
- [ ] После успешного входа вызван `regenerateSession()`, а не сырой
      `session_regenerate_id()`
- [ ] Cookie сессии и заголовки безопасности не переопределены вручную
      в контроллере (они настроены в `ensureSessionStarted()` и
      `sendSecurityHeaders()`)
- [ ] Если таск загружает файлы: тип проверен на сервере по содержимому
      файла, а не по имени; размер ограничен; в папке загрузок
      запрещено исполнение PHP (`.htaccess`)

## Формы и валидация
- [ ] Пустая форма не отправляется — поля подсвечиваются
- [ ] Некорректные данные — поля подсвечиваются с ошибкой

## Код
- [ ] Нет ошибок в консоли браузера
- [ ] Нет PHP ошибок и warnings (проверить storage/logs/app.log)
- [ ] Нет SQL в Controllers и Views
- [ ] Нет неиспользуемых переменных и мёртвого кода
- [ ] Если есть деньги: нигде не хранятся и не считаются как float
- [ ] `composer test` проходит без ошибок
